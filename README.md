# Telegram Userbot: автоответчик, шаблоны, AI, статистика

Userbot на Telethon, который работает от вашего личного аккаунта: отвечает в личных сообщениях
с «человеческой» задержкой, умеет шаблоны с переменными, AI-ответы (OpenAI), ведёт статистику
и имеет защиту от бана. Управление — командами в «Избранное».

## Управление через окно (рекомендуется)

Вместо команд в «Избранное» можно пользоваться окном с кнопками.

- **Windows:** двойной клик по `app.bat` (если окно не открылось — `app_debug.bat` покажет ошибку).
- **Linux/macOS:** `./app.sh` (нужен tkinter: `sudo apt install python3-tk`).

В окне: **Запустить / Остановить**, **Пауза / Продолжить**, переключатель автоответчика,
красная кнопка **PANIC**, живой статус и счётчики, журнал, последние ответы,
редактор шаблонов и настройки (лимит в час, белый/чёрный список, ответ по умолчанию, промпт ИИ).
Команды в «Избранное» при этом продолжают работать, пока бот запущен.

> Первый вход в аккаунт (получение SESSION_STRING) по-прежнему делается один раз через `session.bat`.

## Инструкция для новичка

### ШАГ 0. Что понадобится
- **Python 3.11+** — https://www.python.org/downloads/ (при установке на Windows обязательно поставьте галочку **«Add Python to PATH»**).
- Аккаунт Telegram — **отдельный, не основной!**
- ~10 минут времени.

### ШАГ 1. Получить API_ID и API_HASH
1. Откройте https://my.telegram.org и войдите по номеру телефона.
2. Выберите **API development tools**.
3. Создайте приложение (название и короткое имя — любые, платформа — Desktop).
4. Скопируйте **api_id** (число) и **api_hash** (длинная строка).

### ШАГ 2. Распаковать архив
Распакуйте `userbot.zip` в папку, например `C:\userbot` или `~/userbot`. Внутри должно быть дерево, как выше.

### ШАГ 3. Создать .env
1. Скопируйте `.env.example` → `.env` (скрипт установки сделает это сам).
2. Откройте `.env` в Блокноте/VS Code.
3. Впишите `API_ID`, `API_HASH`, `PHONE` (формат `+7999...`).
4. Остальное оставьте по умолчанию. **Сохраните файл.**

### ШАГ 4. Установить зависимости
(Установка идёт **до** генерации сессии — скрипту сессии нужен Telethon.)
- Windows: двойной клик по `setup.bat`.
- Linux/Mac: `chmod +x setup.sh && ./setup.sh`.
- Вручную: `pip install -r requirements.txt`.

### ШАГ 5. Сгенерировать SESSION_STRING
1. Windows: двойной клик по `session.bat`. Linux/Mac: `./session.sh`.
   (Вручную: `python utils/session_gen.py`.)
2. Введите код, который придёт **в приложение Telegram**, и пароль 2FA, если он включён.
3. Скопируйте длинную строку из консоли и вставьте в `.env`: `SESSION_STRING=...`. Сохраните.

### ШАГ 6. Запустить
- Windows: `run.bat`. Linux/Mac: `./run.sh`. Или `python main.py`.
- В консоли появится «Userbot запущен».

### ШАГ 7. Проверить работу
1. В Telegram откройте «Избранное» и отправьте `/help` — придёт список команд.
2. Отправьте `/status` — покажет состояние.
3. Попросите друга написать вам в личку — через 2–5 минут придёт автоответ (если вы сами не ответили раньше).

### ШАГ 8. Как добавить шаблон
В «Избранное»: `/add "привет" "Привет, {name}! Сейчас {time}, скоро отвечу 🙂"`.
Теперь на любое сообщение со словом «привет» бот ответит этим текстом.
Переменные: `{name}` — имя собеседника, `{time}` — время, `{date}` — дата.
Шаблоны отправляются тем же автоответчиком — с той же задержкой и лимитами.

### ШАГ 9. Как остановить
- `/pause` — временная пауза (`/resume` — продолжить).
- `/autoreply off` — выключить автоответчик.
- `/panic` — аварийный стоп + отключение от аккаунта. Чтобы запустить снова: `python main.py --reset-panic`.
- `Ctrl+C` в терминале.

### ШАГ 10. Что делать, если…
- **«SESSION_STRING invalid / недействительна»** → перегенерируйте (ШАГ 5).
- **FloodWait** → подождите, бот сам обработает (ждёт wait×1.3 и повторяет один раз).
- **Аккаунт ограничен/забанен** → бот @SpamBot, затем recover@telegram.org (см. риски ниже).
- **Бот не отвечает** → `/status` (пауза? лимит? FloodWait-блок?) и файл `userbot.log`.

## Команды

| Команда | Что делает |
|---|---|
| `/autoreply on` / `off` | включить / выключить автоответчик |
| `/pause`, `/resume` | пауза / продолжить |
| `/status` | состояние бота |
| `/tasks` | кому ещё нужно ответить |
| `/add "ключ" "текст"` | добавить шаблон |
| `/del "ключ"` | удалить шаблон |
| `/list` | все шаблоны |
| `/reload` | перечитать файл templates.txt |
| `/stats` | всего сообщений, автоответов, топ-3, FloodWait за сутки |
| `/count @username` | сколько сообщений от пользователя |
| `/log` | последние 20 автоответов |
| `/panic` | аварийный стоп и отключение |
| `/help` | справка |

## Настройки .env

| Переменная | Описание |
|---|---|
| `API_ID`, `API_HASH`, `PHONE`, `SESSION_STRING` | доступ к Telegram |
| `REPLY_DELAY_MIN/MAX` | задержка автоответа, сек (по умолч. 120–300) |
| `MAX_REPLIES_PER_HOUR` | лимит автоответов в час (по умолч. 20) |
| `WHITELIST` / `BLACKLIST` | username (без @) или id через запятую |
| `DEFAULT_REPLY` | фраза, если нет ни шаблона, ни AI |
| `OPENAI_API_KEY`, `OPENAI_MODEL`, `AI_SYSTEM_PROMPT` | AI-ответы (необязательно) |
| `TASK_MAX_AGE_HOURS` | через сколько часов неотвеченное сообщение считается устаревшим (по умолч. 48, 0 = никогда) |
| `CATCHUP_HOURS` | при запуске брать в работу непрочитанные сообщения не старше N часов (по умолч. 24, 0 = выкл) |

## Как бот выглядит для собеседника

1. Через 3–12 секунд сообщение помечается **прочитанным** (две галочки).
2. Пауза `REPLY_DELAY_MIN..MAX`.
3. Несколько секунд собеседник видит **«печатает…»** (чем длиннее ответ, тем дольше).
4. Приходит ответ. Если вы ответили вручную, пока бот ждал или «печатал», автоответ отменяется.

## Пересланные сообщения и очередь «нужно ответить»

**Пересланные и нетекстовые сообщения.** Бот отвечает на пересланные сообщения (отвечает *реплаем* на
пересланное), на фото, голосовые, видео, файлы и т. п. без подписи, и учитывает цитату, если собеседник
ответил на ваше сообщение. ИИ получает их описание вроде `[Пересланное сообщение от Маша] текст` или
`[фото]`. Одиночные стикеры игнорируются (это реакция, а не вопрос).

**Задачи не теряются.** Каждое входящее сообщение сразу записывается в базу как задача и закрывается
только когда на неё ответили (или вы ответили сами). Поэтому:
- **Перезапуск / выключенный компьютер:** при старте бот подхватывает незакрытые задачи и просматривает
  непрочитанные личные чаты, куда писали, пока он был выключен (`CATCHUP_HOURS`).
- **Пауза `/pause`:** сообщения копятся, `/resume` отвечает на накопившееся. (При `/autoreply off`
  и `/panic` новые задачи не создаются.)
- **Лимит в час / FloodWait:** ответ откладывается, а не пропускается.
- **Сбой ИИ:** до 3 попыток, затем фраза по умолчанию; при 5 неудачных отправках подряд бот пишет вам
  в «Избранное», что не смог ответить.
- Несколько сообщений подряд = один ответ на все; если собеседник дописал, пока бот печатает, бот
  отвечает ещё раз.
- Если вы ответили сами, задача закрывается. Задачи старше `TASK_MAX_AGE_HOURS` закрываются, а в
  «Избранное» приходит список, кому ответить вручную.
- `/panic` отменяет все ожидающие задачи.
- Посмотреть, кто ждёт ответа: `/tasks` или счётчик «Ждут ответа» в окне.

## Файл templates.txt

Основной способ добавлять шаблоны: откройте `templates.txt` в Блокноте. Одна строка = один ответ:
`ключ1; ключ2; ключ3 | текст ответа`. Файл загружается при каждом запуске, а `/reload` в «Избранное»
перечитывает его без перезапуска. Шаблоны, добавленные через `/add`, хранятся в базе `userbot.db` и тоже сохраняются.

## Как это работает

- Реагирует **только на личные** сообщения; игнорирует группы, каналы, ботов, «Избранное» и ваши собственные сообщения.
- Приоритет ответа: **шаблон по ключу → AI → фраза по умолчанию**.
- Если вы сами написали в чат за время задержки — автоответ отменяется.
- Если пока идёт задержка собеседник написал ещё — бот ответит один раз, на последнее сообщение.
- Если лимит в час исчерпан (или включена блокировка по FloodWait), автоответ **откладывается** и уходит, как только лимит освободится.
- Автоответы отправляются строго по одному.
- AI использует последние 5 сообщений диалога.

## Защита от бана

- Случайная пауза 1–3 сек перед каждой отправкой.
- FloodWait: ожидание `wait × 1.3` сек, один повтор, запись в счётчик.
- 3 FloodWait за 24 часа → автоответы блокируются, уведомление приходит в «Избранное».
- Лимит автоответов в час (`MAX_REPLIES_PER_HOUR`).
- `/panic` — мгновенно отменяет все запланированные ответы и отключает бота. Флаг сохраняется в БД, поэтому после перезапуска бот не стартует, пока вы не запустите `--reset-panic`.

## Риски и безопасность

- Telegram может ограничить или заблокировать аккаунт за userbot-активность. Используйте **ОТДЕЛЬНЫЙ аккаунт**, не основной.
- Не делайте массовых рассылок — это самый быстрый путь к бану. Бот создан только для ответов на входящие.
- При FloodWait не пытайтесь обойти ограничения — бот ждёт автоматически.
- Держите `/panic` наготове.
- `SESSION_STRING` = полный доступ к аккаунту. Никому не показывайте, не коммитьте `.env` (он в `.gitignore`).
- Про письмо на recover@telegram.org: это адрес для обращений **после** блокировки аккаунта. Заранее «согласовывать» userbot там не нужно и это ничего не гарантирует. Если аккаунт ограничен, сначала напишите @SpamBot, затем в поддержку.
- Использование OpenAI передаёт текст переписки (последние 5 сообщений) третьей стороне. Отключите AI, убрав `OPENAI_API_KEY`.
